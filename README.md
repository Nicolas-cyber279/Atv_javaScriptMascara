# Atividade JavaScript - Mascara

Um site formulário feito para treinar habilidades de JavaScript.

## Sobre o Projeto

Esta é uma atividade proporcionada pelo professor Paulo Henrique para que seus alunos desenvolvessem a lógica e sintaxe de JavaScript ensinada em sala de aula através de um site feito com um formulário simples em Html e Css.

O site formata automaticamente o texto digitado dependendo do campo de entrada escolhido.

## Funcionalidades

*Formatação automática de texto
*Mensagem padrão de envio de formulário
*Limpeza de campos automática

##Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**
